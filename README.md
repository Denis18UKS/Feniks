# Feniks AI Studio

Локальная desktop-среда для создания и обучения ИИ-моделей и автономных агентов. Интерфейс работает в окне PyWebView, Python отвечает за проекты, чаты, задания и структурированные журналы, а подготовленный C# bridge предоставляет точку расширения для Windows-интеграций.

## Быстрый запуск

```bash
python -m venv .venv
.venv\Scripts\activate              # Windows
pip install -r requirements.txt
python app.py
```

В Linux активация окружения выполняется командой `source .venv/bin/activate`.

## Возможности текущей версии

- раздельные рабочие пространства агентов, моделей, дообученных моделей и обучения;
- создание и удаление собственных агентов без предустановленных демо-записей;
- независимые чаты-вселенные, копирование контекста в новую ветку и удаление чатов;
- надёжное автосохранение агентов, сообщений, режимов, темы и журналов в SQLite;
- режимы «наблюдатель», «советник», «помощник» и «автономный»;
- локальное хранение состояния в SQLite;
- структурированные логи с категориями, уровнями и фильтрами;
- отдельный поиск внутри каждого раздела;
- светлая и тёмная темы;
- C# Windows bridge с JSON-протоколом и безопасным списком команд;
- сборка Windows `.exe` через PyInstaller.

> Интерфейс больше не имитирует ответы модели: пока провайдер модели не настроен, сообщение честно сохраняется без фиктивного ответа. Подключение локальных/облачных моделей, реальное управление экраном, голос и игровые адаптеры являются следующими модулями. Автоматизация соревновательных игр должна использоваться только в разрешённых локальных и тренировочных средах.

## Первый запуск

1. Нажмите **«Новый агент»**, укажите назначение и безопасный начальный режим.
2. В рабочем пространстве агента нажмите **«Новый чат»**. Каждый чистый чат имеет независимую историю; опция копирования создаёт отдельную ветку текущего диалога.
3. Отправленные сообщения сразу записываются в локальную базу. При повторном запуске агент, чаты и переписка восстановятся автоматически.
4. Проверяйте операции во вкладке **«Журнал событий»** — там нет неструктурированного технического вывода.

Пользовательские данные находятся вне папки приложения: `%LOCALAPPDATA%\FeniksAIStudio` на Windows либо стандартный каталог приложений текущей ОС.

## Сборка `.exe`

На Windows запустите:

```powershell
.\scripts\build_windows.ps1
```

Скрипт собирает C# bridge (если установлен .NET SDK), устанавливает зависимости и создаёт `dist/FeniksAIStudio.exe`. Данные пользователя сохраняются отдельно в `%LOCALAPPDATA%\FeniksAIStudio` и не теряются при обновлении exe-файла.

## Проверки

