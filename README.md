# Feniks AI Studio

Локальная desktop-среда с постоянными агентами, независимыми чатами, структурированными журналами и настоящим подключением к Ollama либо OpenAI-совместимому chat API. Незавершённые модули (обучение, зрение, голос и игровые адаптеры) явно отмечены в интерфейсе и не имитируют работу.

## До первого запуска (Windows)

Требуется **64-битный Python 3.14**. Проект обновлён на PyWebView 6.2.1 и PyInstaller 6.21; старое окружение на PyWebView 5 необходимо пересоздать. Также нужен Microsoft Edge WebView2 Runtime (обычно уже есть в Windows 10/11).

```powershell
cd "C:\путь\к\Feniks"
py -3.14 -m venv .venv
Set-ExecutionPolicy -Scope Process Bypass
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python app.py
```

Ошибка `Rectangle.op_Equality ... DesktopApi` исправлена: внутренние Python-объекты больше не передаются в рекурсивное публичное API PyWebView. Если используется старое окружение, удалите `.venv`, создайте его заново командами выше и убедитесь, что запускаете обновлённый код.

## Настройка после запуска

1. Нажмите **«Подключение модели»** внизу слева.
2. Для Ollama установите Ollama, выполните `ollama pull qwen3:8b`, выберите **Ollama**, URL `http://localhost:11434`, модель `qwen3:8b`. Ollama должен быть запущен.
3. Для OpenAI-совместимого сервера выберите соответствующий режим, укажите URL до API, заканчивающийся на `/v1` (например `http://localhost:1234/v1`), имя модели и при необходимости ключ.
4. Создайте агента. Его назначение используется как системная инструкция.
5. Создайте чистый чат или независимую копию текущей ветки и отправьте сообщение. Запрос выполняется моделью, оба сообщения сохраняются в SQLite.
6. Ошибки подключения и успешные ответы доступны в **«Журнале событий»** отдельными структурированными событиями.

Данные находятся в `%LOCALAPPDATA%\FeniksAIStudio` (обычно файл `feniks.db`). Не удаляйте эту папку, если хотите сохранить агентов и переписку.

## Повторный запуск

```powershell
cd "C:\путь\к\Feniks"
.\.venv\Scripts\Activate.ps1
python app.py
```

## Сборка `.exe`

Установите .NET 8 SDK, если нужен C# bridge, затем:

```powershell
.\scripts\build_windows.ps1
```

Результат: `dist\FeniksAIStudio.exe`. Для конечного пользователя отдельный Python не требуется; WebView2 Runtime требуется.

## Реальные границы версии

Все вкладки открывают отдельные рабочие каталоги: базовые модели, дообученные модели, датасеты, конфигурации обучения, источники зрения, голосовые профили и игровые сессии. В каждом разделе работают создание, поиск, хранение JSON-параметров и удаление записей. Это менеджер конфигураций: фактический запуск стороннего ML-фреймворка, OCR/захвата, аудиодвижка или игры требует указать и установить соответствующий внешний инструмент в параметрах записи. Автоматизацию игр следует использовать только в одиночных/локальных тренировочных средах и без обхода античита.
